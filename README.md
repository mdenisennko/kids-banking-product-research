# Исследование рынка детских банковских карт

## О проекте

Практико-ориентированный проект НИУ ВШЭ, выполненный совместно с аналитической компанией Frank RG для банка из ТОП-5.

Цель проекта — исследовать рынок детских банковских продуктов, изучить пользовательский опыт детей и родителей и сформулировать рекомендации по развитию продукта.

## Задачи

В рамках проекта:

- исследовала российские и международные практики;
- анализировала продукты банков-конкурентов;
- участвовала в проведении глубинных интервью с родителями и детьми;
- систематизировала пользовательские потребности;
- участвовала в построении Customer Journey Map;
- анализировала боли и барьеры пользователей;
- формулировала рекомендации по развитию банковского продукта.

## Подход

### 1. Анализ рынка

Изучение существующих решений и международных практик на рынке детских банковских продуктов.

### 2. Конкурентный анализ

Сравнение продуктов банков-конкурентов по ключевым характеристикам и пользовательским сценариям.

### 3. Пользовательское исследование

Проведение глубинных интервью с родителями и детьми для изучения их потребностей, ожиданий и проблем.

### 4. Customer Journey Map

Структурирование пользовательского пути и определение ключевых точек взаимодействия с продуктом.

### 5. Рекомендации

Формирование предложений по развитию продукта на основе результатов исследования.
